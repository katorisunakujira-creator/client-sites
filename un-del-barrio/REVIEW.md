# un.DEL.BARRIO — 店舗確認用サイトサンプル

白を基本色に、赤い店舗ロゴと料理写真を生かした1ページのサンプルです。ユーザーの「使える画像を使ってください」という指示に沿って、取得できた素材で制作しました。**掲載内容の店舗確認が必要なサンプル**です。このフォルダだけで配信でき、リポジトリ全体の設定や既存店舗の変更を必要としません。

## 確認方法

GitHubから取得した場合は、このフォルダで下記のHTTPサーバーを起動してください。HTML・CSS・表示画像だけで動作し、追加ライブラリのインストールは不要です。元画像はクラウド作業フォルダの `images/originals/` に保管し、GitHubにはサイトの表示用画像を含めています。

HTMLを直接開く操作は、このクラウドのブラウザが `file://` を管理ポリシーで拒否するため未検証です。画像を含むページの動作は、下記のHTTP配信で確認済みです。通常のブラウザで直接開けない場合も、HTTP配信の手順を使用してください。

クラウド作業フォルダには確認用ZIP `review/un-del-barrio-sample.zip` と実ブラウザの画面 `review/desktop-full.png`、`review/mobile-full.png` も生成しています。ZIP・画面画像・サーバーログはGit管理対象外です。検証結果 `review/verification.json` はリポジトリにも含めています。

HTTP配信する場合、この店舗フォルダで以下を実行します。

```sh
python3 -m http.server 8001 --bind 127.0.0.1 --directory .
```

同じ端末のブラウザで `http://127.0.0.1:8001/` を開きます。クラウド環境のlocalhostは利用者の端末のlocalhostとは異なります。この作業では外部公開やプレビュー用の外部ホスティングは行っていません。

## 作成したもの

- `index.html`：トップ、お店の紹介、4種類のメニュー、写真、営業時間、アクセス、公式Instagram。
- `styles.css`：白・赤・濃いグレーの配色。スマートフォンからPCまで対応。
- `images/*.webp`：表示用画像。写真は縦横比を保ち、追加のトリミングをしていません。
- `images/originals/`：取得できた25ファイルの元画像。クラウド作業フォルダにファイル名・内容を保管し、Git管理対象外。
- `references/`：表示画像の対応表。提供記事の原文、全素材の確認記録、既存ファイルの保全確認用ハッシュはローカルのみで保管。
- `review/`：Git管理する検証結果と、ローカル生成の確認画面・確認用ZIP。

JavaScript、外部フォント、フレームワーク、外部画像、埋め込み地図は使用していません。リンク先へ移動するまで第三者サイトへのリクエストはありません。

## デザイン・写真の扱い

白い背景に赤いロゴを置き、料理の黄色・緑・茶色が主役になるようにしています。スマートフォンではトップに料理写真を先に見せ、店名と料理が最初に伝わる順番にしました。料理4種は写真と読めるテキストを並べています。人物イラストはInstagram案内の1か所だけに使っています。

ヘッダーのロゴは提供メニュー画像 `line_oa_chat_260807_164545.jpg` の上部にある横組みの店舗ロゴです。画像を保存し、SVGの表示範囲でロゴ部分だけを見せています。図形や文字の描き直し、色変更、背景除去はしていません。先に会話で見せていただいた単独ロゴ `line_oa_chat_260807_164541.jpg` の元ファイルは未受領ですが、代わりに今回の添付内にある実際の店舗ロゴを使用できています。

取得・確認できたのは25ファイル（重複を除く24種類）です。「写真20枚を確認済み」という意味ではありません。最終指示に従い取得可能な素材で完成させています。取得したファイルに破損や読めない画像はありません。店内全体を見渡す写真は取得素材に含まれていないため、紙袋の写真と店頭入りの店舗ビジュアルを使用しています。

`line_oa_chat_260807_164551.jpg` は `line_oa_chat_260807_164545.jpg` と同じ内容です。原本は両方保持し、サイトでは片方のみ使用しています。

採用した9種類の素材と不採用素材の内容は `references/assets-upload-01.json` と `references/assets-upload-03.json` に記録しています。表示画像15ファイル（大小サイズを含む）の対応表は `references/display-assets.json` です。元画像のSHA-256を保存し、変換後も一致することを確認しています。表示用画像のみWebPに変換・縮小し、EXIFの向きを反映しました。料理、人物、文字を消したり追加したりしていません。

## 検証と限界

実ブラウザ（Chromium / Playwright）で320 / 390 / 768 / 1024 / 1440pxの5幅を検証し、全5ケースで画像の読み込み、画像の縦横比、横スクロールのないレイアウト、ページ内リンク、キーボード操作、指定営業時間と8件のメニュー価格が合格しました。JavaScript例外・素材の読み込みエラーはなく、外部リクエストもありません。最終結果は `review/verification.json` に記録しています。確認画像も今回の素材反映後の内容へ更新しています。

InstagramのURLは記事内のリンクと照合済みですが、外部サイト上での最新内容は未確認です。Googleマップは住所を指定した検索リンクであり、店舗登録のピン位置を検証したものではありません。外部リンクへの遷移先表示、現在の営業内容の正しさは、上記の店舗確認が必要です。

既存の `forest`、`forest/forest`、README、リポジトリ全体や公開設定は変更していません。作業開始時の7ファイルとSHA-256で照合し、一致を確認済みです。制作・生成ファイルはすべて `un-del-barrio` 内です。
